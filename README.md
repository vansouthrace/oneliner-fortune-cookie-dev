One original fortune-cookie line for a software developer, written for the [make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

A fortune cookie speaks in small, true observations; this one is about the quiet lie a green test tells.

## Entry

> A passing test is not proof. It is a rumor the code started about itself.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
